# finance
(Пока) экспериментальная версия торгового робота для изучения акторной модели.

## Примеры
Примеры находятся в папке /examples

Проверка связи с Quik через lua скрипты.
```
go run ./examples/helloquik -port 34132
```

Генерация случайных сигналов и их исполнение "на бумаге".
```
go run ./examples/trader
```
